# 《黄雀在后》城市实景剧本杀

> 螳螂捕蝉，黄雀在后。——一场跑男式的城市寻宝，一桩二十年前的悬案，一个藏在你们中间的人。

**类型**：奔跑吧风格 · 城市实景 · 剧情推理 · 撕名牌
**人数**：6名玩家 + 1名主持人（NPC"管家"）
**时长**：约3.5小时
**场地**：任意城市商圈/老街/公园，5个打卡点（本剧本不绑定具体城市，主持人按《道具物料清单》自行选点）

---

## 一句话简介

百年老字号"德昌号"的老掌柜临终前设下一场寻宝局：六位与二十年前"配方失窃案"有着千丝万缕关系的人被请柬召集，穿越城市完成五道关卡、拼出真相——但味莱集团重金收买的"黄雀"就混在其中，伺机偷走真配方。

## 玩法特色

- **跑男式任务**：传声筒猜词、城市寻物挑战、指压板猜拳淘汰赛、密码箱解谜、终局撕名牌大战
- **剧本杀内核**：每人一本角色书，有公开身份、隐藏秘密、个人任务；1人是内鬼"黄雀"，1人握有"反水"抉择
- **金币经济**：关卡赢"德昌铜钱"，终局商店可买护身符（免撕一次）、情报卡、加票权
- **三种结局**：真相大白 / 黄雀得手 / 错怪好人，由玩家的推理和终局表现决定

## 快速开始（主持人三步走）

1. **读**：通读《主持人手册》和《世界观与真相》，按《道具物料清单》采购打印（约1小时准备）。
2. **选点**：在你的城市选5个步行可达的打卡点（奶茶店→文创店→公园→书店→广场），藏好宝箱。
3. **开局**：集合玩家，发角色本（角色分配见主持人手册），照着主持词走流程即可。

> ⚠️ **剧透警告**：玩家只能看《公共规则书》和自己的角色本。其余文件全部剧透。
